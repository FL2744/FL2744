# William Taggart

I work at the intersection of **artificial intelligence and the humanities**.

My projects explore how large language models can be used to better understand translation, culture, and creative expression. 

The course site for my FL 2744: AI and Global Languages class is here: **[l1001.vt.domains](https://l1001.vt.domains)** 

### Current interests

- Large language models and multilingual AI
- Machine translation and translation evaluation
- AI and global languages
- Digital humanities
- AI-assisted research and data analysis
- Tools for teaching and learning about AI
